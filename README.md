# Vehicle Maintenance Tracker

## Project Description
Vehicle Maintenance Tracker is an Android application developed for COM-437 Android Programming at Saint Leo University. It helps vehicle owners manage multiple vehicles, track mileage, record maintenance history, and monitor upcoming services. Vehicle information and maintenance records are stored locally for offline access.

## Key Features
- Add and manage multiple vehicles.
- Enter vehicle information manually or decode a VIN using the NHTSA API.
- Track vehicle mileage and maintenance intervals.
- View upcoming maintenance reminders based on mileage and time.
- Record completed services and maintenance history.
- Customize maintenance schedules and exclude services that do not apply to a vehicle.
- Store vehicle and service information locally for offline access.

## Programming Languages
- Java: Application logic and functionality.
- XML: User interface layouts and design.

## Development Tools and Technologies
- Android Studio: Development, building, and testing.
- Gemini AI: Development and troubleshooting assistance.
- Android SDK and Emulator: Testing and debugging.
- Room Database and SQLite: Local storage and database management.
- NHTSA vPIC API: Vehicle identification number decoding.
- GitHub: Source control and project documentation.

## Installation Instructions
1. Download or clone the repository after the complete application source code has been uploaded.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize the project dependencies.
4. Run the application using a compatible Android emulator or physical device running Android 7.0 (API 24) or newer.
