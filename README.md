**VEHICLE MAINTENANCE TRACKER**
This tracker is an Android application being developed for COM-437 Android Programming at St. Leo University.

This application is designed to help vehicle owners track routine maintenance and monitor upcoming maintenance.

**Planned Features**
- VIN based identification using NHTSA.
- Mileage tracking
- Maintenance and service records
- General maintenance and service intervals
- Customizable maintenance schedules
- Upcoming maintenance reminders
- Local storage of vehicle information

**Development Tools**
- Android Studio
- Java
- XML
- GitHub
- NHTSA VIN decoder API
